# Глоссарий

## Назначение

Глоссарий фиксирует основные термины проекта `Универ`. Он нужен, чтобы в документации и ВКР одни и те же понятия использовались одинаково.

| Термин | Значение |
| --- | --- |
| Пользователь | Учетная запись человека, который работает с приложением. |
| Гость | Неавторизованный посетитель приложения. |
| Профиль | Публичная или личная страница пользователя с данными и публикациями. |
| Публикация | Основная единица пользовательского контента: заголовок, описание, текст и изображения. |
| Автор | Пользователь, создавший публикацию. |
| Издатель | Сущность, от имени которой опубликована запись: пользователь или сообщество. |
| Комментарий | Сообщение пользователя, связанное с публикацией. |
| Ответ | Комментарий, который связан с другим комментарием как дочерний элемент. |
| Лайк | Отметка пользователя о положительной реакции на публикацию. |
| Подписка на пользователя | Связь, при которой один пользователь отслеживает публикации или активность другого. |
| Сообщество | Тематическая область внутри приложения, объединяющая участников и публикации. |
| Владелец сообщества | Пользователь с полными правами управления конкретным сообществом. |
| Модератор сообщества | Пользователь, которому владелец делегировал часть прав управления сообществом. |
| Участник сообщества | Пользователь, связанный с сообществом через роль. |
| Подписка на сообщество | Связь пользователя с сообществом для получения его публикаций. |
| Черный список сообщества | Список пользователей, которым ограничено взаимодействие с конкретным сообществом. |
| Журнал действий | История модерационных и управленческих действий внутри сообщества. |
| Жалоба | Обращение пользователя на публикацию или другого пользователя для проверки администратором. |
| Администратор | Пользователь с системными правами для обработки жалоб, пользователей и заявок. |
| Заявка на верификацию | Запрос на подтверждение статуса сообщества. |
| Уведомление | Системное сообщение о событии, важном для пользователя или администратора. |
| Мягкое удаление | Подход, при котором запись помечается удаленной через поле `deletedAt`, но физически остается в базе данных. |
| API-процедура | tRPC-операция, которую клиент вызывает для чтения или изменения данных. |
| Общий контракт | Типы и схемы, которые одновременно используются клиентом и сервером. |
