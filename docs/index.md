# Универ

`Универ` - клиент-серверное приложение социальной платформы для публикации материалов, общения пользователей и работы с тематическими сообществами.

Документация фиксирует техническую часть проекта: состав системы, архитектуру, модель данных, API, развертывание и проверку работоспособности.

## Состав проекта

Репозиторий организован как monorepo на TypeScript:

- `webapp` - клиентское приложение на Expo, React Native и React Native Web.
- `server` - серверная часть на Express, tRPC и Prisma.
- `shared` - общие типы, схемы валидации и контракты между клиентом и сервером.

В исходном коде и пакетах используется техническое имя `somnia`. В документации и пользовательском описании проект называется `Универ`.

## Технологическая основа

Клиентская часть построена на Expo, React Native и React Native Web. Серверная часть использует Express, tRPC, Prisma ORM и PostgreSQL. Общие типы и схемы валидации вынесены в пакет `shared`, чтобы клиент и сервер работали с единым контрактом данных.

Внешние сервисы используются точечно: Cloudinary отвечает за изображения, Redis может подключаться как кэш, Sentry используется для ошибок, Mixpanel - для клиентской аналитики.
