# API

## Общая характеристика

API проекта `Универ` реализован через tRPC. Клиент и сервер используют общий TypeScript-контракт, поэтому вызовы API типизированы без отдельного REST-описания.

Сервер публикует tRPC API по пути `/trpc`. В режиме разработки также доступен `/trpc-playground`.

Этот документ является справочником процедур. Детали серверной реализации описаны в [backend.md](./backend.md), а причины выбора tRPC - в [decisions.md](./decisions.md).

## Принципы организации

Процедуры API сгруппированы по функциональным областям в `server/src/router`.

Входные данные валидируются через Zod-схемы. Часть схем находится в `shared`, чтобы использовать один и тот же контракт на клиенте и сервере.

Авторизованный пользователь доступен в контексте процедуры как `me`. Если процедура требует входа или специальных прав, она проверяет это в серверной логике.

## Группы процедур

| Группа | Назначение |
| --- | --- |
| `auth` | Регистрация и вход. |
| `users` | Профили, аватары, пароль, подписки, блокировки. |
| `posts` | Лента, публикации, лайки, удаление и восстановление. |
| `comments` | Создание, получение и удаление комментариев. |
| `communities` | Сообщества, подписки, аватары, заявки на верификацию. |
| `moderation` | Модерация сообществ, роли, черный список, журнал действий. |
| `notifications` | Получение и отметка уведомлений. |
| `reports` | Создание жалоб. |
| `admin` | Административные списки, жалобы, пользователи, заявки. |
| `search` | Поиск пользователей и сообществ. |
| `upload` | Подготовка загрузки изображений в Cloudinary. |

## Обработка ошибок

Серверный tRPC слой использует общий формат ошибок. Ожидаемые ошибки помечаются отдельным флагом `isExpected`, чтобы клиент мог отличать бизнес-ошибки от неожиданных исключений.

Неожиданные ошибки на клиенте отправляются в Sentry, а на сервере логируются через общий логгер.

## Авторизация запросов

Клиент добавляет JWT-токен в заголовок:

```text
Authorization: Bearer <token>
```

Сервер извлекает пользователя, помещает его в контекст и использует при проверке доступа к процедурам.
